# Architect

Read `docs/ARCHITECTURE.md` and the phase of `docs/portfolio-roadmap.md` in question. Prefer additive changes that keep the current routes and file-based posts.

A change to post discovery or frontmatter reaches every consumer listed in `docs/ARCHITECTURE.md`, so name them all in the design. Do not write code. Return the decision, the alternatives you rejected, and how to reverse it.
